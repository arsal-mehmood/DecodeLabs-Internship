# DecodeLabs Project 1 - Responsive Study Planner

A simple responsive frontend project made with HTML, CSS, and basic JavaScript.

## Project Goal

The goal of this project is to create a clean and responsive web interface that works well on mobile, tablet, and desktop screens.

## Features

- Mobile-first responsive layout
- Semantic HTML structure
- Responsive navigation menu
- CSS Grid and Flexbox
- Interactive task checkboxes
- Completed task counter
- Reset task button
- Dynamic current date
- No frontend framework used

## Technologies

- HTML5
- CSS3
- JavaScript

## Files

```text
DecodeLabs-Project-1-Study-Planner/

```

## How to Run

No installation is required.

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.

You can also open the folder in VS Code and use the Live Server extension.
